# Mi Rey Taquería & Grill — Opción 1 (Azul / Logo)

Sitio web en **Next.js** para Mi Rey Taquería & Grill (Wilmington, NC).

Esta versión usa la paleta del **logo**: azul marino, oro y crema — estilo elegante y clásico.

## Correr en local

```bash
npm install
npm run dev
```

Abre http://localhost:3000

## Producción

```bash
npm run build
npm start
```

## Despliegue recomendado (link para el cliente)

Importa este repo en [Vercel](https://vercel.com) → genera una URL en vivo automáticamente
(sin configuración). Ideal para enviar al cliente y que vea el sitio funcionando.
